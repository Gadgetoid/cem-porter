    Icon Lab

    Keep on keeping on!

    Replaces or adds the icons in a Windows CE program, from a picture, an .ico or another program.

    Using it

    • Open the program to change, and pick one of its icons. The first is the one Explorer and the Start menu show.
    • Open a picture, an .ico, or a program to take an icon from.
    • Choose the sizes and colours. 4 greys suits CE 1.0 and greyscale devices; 16 or 256 colours suit colour CE 2.0 devices. Each device picks the best one it can show.
    • Replace the selected icon or add a new one, then save the program.

    What it does

    • Pictures are scaled to each size, and pixels less than half opaque become transparent.
    • The program's resources are rebuilt with the new icons. If they no longer fit where they were, they move to a new section at the end of the file.
    • ROM Explorer's Open in Icon Lab sends a program straight here.

    Limitations

    • 16 colours uses the standard Windows palette; 256 colours makes a palette from the picture.
    • A program that checks its own size or checksum may refuse to run once changed.
