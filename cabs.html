CAB Maker

Keep on keeping on!

Gets the CAB you copy to the device out of a desktop installer, for any CPU and Windows CE version. Nothing is ported.

Using it

  • Open a desktop installer, CAB, zip, 7z, LZH or CD image. Open data1.cab together with data1.hdr and further volumes.
  • Each CE CAB inside is listed and saved exactly as shipped, signature included.
  • Programs that come as an H/PC Explorer .load script or loose files get a CAB built for their own CPU.
  • Copy the CAB to the device and tap it to install.
  • Built MIPS, SH3 and ARM programs also get a self-installing Setup .exe, for CE 1.0 or any device without CAB support. Run it again to remove the program.

Limitations

  • CE 1.0 has no CAB installer: use the Setup .exe.
  • A built CAB holds one setup DLL.
  • To run a CE 2.11 or later program on CE 2.0 or 1.0, port it with CEM Porter.
