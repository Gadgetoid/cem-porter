CEMSync

Your device, no period PC required.

Talks to a Windows CE device over USB from the browser. The Casio BE-300 is the first target.

Using it

  • Connect the cradle, press Connect, and choose the device when the browser asks.
  • The device answers with its Unit ID and the names of its system and user disks.
  • Drop a .cbea to see what it installs, then send it. Any other file is copied as is.
  • Back up flash reads all 16 MB, the OS partitions included, and saves it.

Needs

  • Chrome or Edge. Safari and Firefox do not implement WebUSB.
  • On Linux, a udev rule, or the kernel's ipaq driver will claim the device first.

How it works

The BE-300 speaks Casio's own PC Connect protocol rather than ActiveSync. The host asserts DTR and RTS, trades 0x55 twice, then sends framed commands. The device drops off the bus about 115 ms after connecting if nothing follows, so the first command goes out immediately.

Flash reads below the file system use a negative sector offset: the driver maps the user volume at physical sector 7584 and only bounds checks the top of its window, so the OS partitions are readable through the ordinary call.
