Font Converter

Keep on keeping on!

Turns a desktop font into a TrueType or bitmap font that Windows CE 1.0 and 2.0 handhelds can use.

Using it

  • Get a font from fonts.google.com and drop the zip here, or open a .ttf, .otf or .woff.
  • Pick the font in the list. For a variable font, pick an instance or set the axes.
  • CE 2.0 and later use TrueType; CE 1.0 and some CE 2.0 devices only have bitmap fonts.
  • Choose the characters, check the preview, and save the font, a CAB or a self-installing .exe.
  • Soft reset the device after installing so it loads the new font.

What it does

  • TrueType: keeps only the chosen characters and the tables CE's rasterizer reads, converts PostScript curves to TrueType ones, and can drop outline points and round to fewer units per em to save space.
  • Bitmap: draws each size as a 1-bit .fnt like the ones in CE ROMs, using the font's hinting where it has some.

Limitations

  • TrueType output has no hinting, so small sizes look softer than hinted ROM fonts. Bitmap fonts are sharper at small sizes.
  • Characters outside the Basic Multilingual Plane, colour glyphs, kerning and ligatures are dropped.
  • Check the font's licence. Fonts with a Reserved Font Name need a new family name once modified.
