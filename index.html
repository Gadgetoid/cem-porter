CEM Porter

Keep on keeping on!

Ports Windows CE 2.11 and 2.0 programs and their installers back to CE 2.0 and 1.0 for MIPS and SH3 handhelds.

Using it

  • Open a desktop installer, CE CAB, zip, 7z, LZH, CD image or program.
  • Pick a build, untick any files you don't want, and choose the device.
  • Port, read the report, and save a CAB (CE 2.0), a self-installing .exe (CE 1.0 and 2.0) or the files.
  • Run a self-installing .exe again to remove what it installed.
  • A build that came as a CE CAB can be saved as shipped with Save original CAB, for any CPU and CE version, ready to copy to the device.

What it changes

  • CE 2.11 programs: system calls renumbered for CE 2.0, C runtime from VELOCRT.DLL. Palm-size PCs share later numbering, so only the few functions they lack or name differently change.
  • CE 2.0 programs for CE 1.0: imports renamed or supplied by CE1COMPAT.DLL and VELOSHIM.DLL, direct kernel calls adapted, colour bitmaps reduced to 4 greys.
  • Setup DLLs run: wceload runs them from a CAB, the self-installer on CE 1.0.
  • MIPS programs built for 1 KB pages are moved to 4 KB pages for the Velo's R3910.

Limitations

  • Programs needing MFC 2.11 or Visual Basic need those runtimes installed separately.
  • On CE 1.0, programs built on CE 2.0 components (command bands, OLE storage, IMGDECMP, CE 2.0 Office) won't run. The report lists missing DLLs and functions.
  • A CAB holds one setup DLL, so a merged build keeps only the first.
  • A clean report doesn't guarantee a program runs. Please report what you find.
