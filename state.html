State Explorer

Keep on keeping on!

Opens a saved state from velo-emu or sh3emu and shows the files and registry in its RAM, without running it.

Using it

  • Open a state or snapshot: state-*.bin from the emulator's data folder, or a snapshot or backup from its snapshots folder.
  • Double-click a folder to open it, or a file to see its properties and preview it.
  • Save the selected files, or everything as a zip with the registry as a .reg file.
  • Registry browses the keys and values; Save .reg exports them all.
  • State details shows the emulator, when it was saved, the object store and the records in the file.

What it reads

  • Windows CE 1.0 to 2.12 object stores: files, folders and the registry.
  • On CE 1.0 and 1.01 the registry comes from \Windows\Pegreg.reg or CEreg.reg, as filesys last wrote it.

Limitations

  • Only files in RAM are listed. Files in ROM aren't in the state; open the ROM in ROM Explorer for those.
  • Databases (contacts, calendar, tasks, mail) are counted but not read.
  • A state saved before CE made its object store has nothing to show.
