Hex Annotator

Keep on keeping on!

An annotated hex viewer and patcher for Windows CE executables. It reads a PE and labels what the bytes mean, in toggleable layers, so you can find and change the part you care about and save a patched file.

Using it

  • Open a .exe, .dll or any binary - or send a module straight from ROM Explorer with its "Open in Hex" button, no saving first.
  • Turn annotation layers on and off for the job at hand: PE structure, section bodies, strings, imports, relocations, and patch sites. Each colours the bytes it understands.
  • Patch sites flags likely "make this check pass" edits (MIPS boolean-return tails, ARM return stubs) and offers a ready one-click patch to try. It surfaces candidates to test, not guaranteed cracks.
  • Click a byte to inspect it: every enabled layer that covers it is listed, so you see at once that a word is, say, inside .text, part of a string, and a relocation.
  • Type hex digits over a selected byte to edit it; arrow keys move. Changed bytes turn red. Revert undoes all edits; Save patched writes a copy.
  • Go to jumps to an offset; Find takes hex bytes (01 00 a0 e3) or text in quotes ("Register").

Where it's going

  • More layers plug into the same interface: a fuller disassembler, and more patch-site heuristics anchored by strings and imports (to pinpoint gate-style checks a blind scan can't).
  • A future export will turn a patch into a small on-device .exe that finds and patches a compatible file in place.

Limitations

  • Edits are byte-for-byte in place; it doesn't grow sections or fix checksums.
  • String detection is ASCII and UTF-16LE runs of four or more; it isn't exhaustive.
