Package Explorer

Keep on keeping on!

Opens an installer or archive and shows everything inside it, including installers inside installers, without porting anything.

Using it

  • Open a package: CAB, InstallShield, Installer VISE, zip, 7z, LZH, SZDD, PKWARE DCL, CASIO .cpk or .cbea, a CD image (.iso, or raw .bin or .mdf), or an installer holding any of these. Open data1.cab together with data1.hdr and further volumes.
  • Each container is a folder. Double-click a file to see its properties and preview it.
  • In a CE CAB, files are named as they install; Properties shows the stored name and install path. The CAB's folder and its .000 setup file show the program, files, registry entries and shortcuts.
  • Save a file, a folder as a zip, or everything as a zip. Save all asks whether to unpack every package, or save the open folder with the packages in it kept whole. Save container in a container's Properties saves it whole. Files are saved exactly as stored.

Limitations

  • Containers nested more than six deep are left packed.
  • Dates aren't kept.
