CEM Compat

Keep on keeping on!

Checks a Windows CE program or DLL against the ROMs of every device CEM Compat knows, from CE 1.0 to Windows Embedded Compact 2013, and says whether it runs, why not, and whether CEM Porter can port it.

Using it

  • Open a program, DLL, CAB, installer or archive, and pick a binary from it.
  • Each device row shows the overall result and each check. Tap a row for the details.
  • DLLs that come in the same package count as present.

Results

  • Runs as is: everything it needs is on the device.
  • CEM Porter patches it: renumbered system calls, functions CEM Porter supplies, CE version, direct kernel calls, 4 KB pages.
  • Might be made to work: a few functions missing, a runtime to install, a newer CE version than the device's.
  • Won't work: another CPU, many missing functions, DLLs nobody supplies, too big for RAM.

Limitations

  • Only imports are checked: a program can still fail on screen size, hardware or registry settings.
  • Ordinal imports are named from the nearest older ROM of the same CPU.
  • The amber and red split for missing functions is a guess.
